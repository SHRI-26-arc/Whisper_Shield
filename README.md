# Whisper Shield

A beginner-friendly Flutter starter app for a women's safety concept.

## What is included

- Emergency-focused home screen
- Large SOS activation button
- Protection status with toggle
- Emergency contacts section
- Quick location-sharing toggle (demo state only)
- Check-in action
- Settings bottom sheet
- Responsive Material 3 styling
- No third-party packages

## Run it

1. Install Flutter and make sure `flutter doctor` is healthy.
2. Open this folder in VS Code or Android Studio.
3. Run:

```bash
flutter pub get
flutter run
```

## Important

The SOS, phone, location-sharing, and check-in actions are UI/demo behaviors only.
For a real safety product, connect them to carefully designed and tested emergency,
calling, messaging, location, authentication, and privacy services.
